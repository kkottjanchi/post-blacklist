2. 콘셉트
먹칠이 걷히면 색이 돌아온다
끝까지 싸워라 = 먹칠(검열, 지워진 이름)
사랑스럽고 다정하게 = 무지개 잉크 번짐(SEMI가 v4에 쓴 웃는 얼굴 영상)
종이색은 영상 바탕색(EDDDB9)에 맞춰 영상이 종이 위에 번진 것처럼 보이게 함

3. 구성
첫 화면: 무지개 잉크 영상 + 큰 글자 "이후" + 먹칠이 벗겨지며 드러나는 문장 "9473명의 이름이 지워진 자리에서 우리는 계속 만들어간다"
01 지워진 이름들: 9,473 숫자 + 검은 막대 벽. 막대 하나가 한 사람의 이름이고, 화면을 내리면 절반이 제각각의 색을 되찾음
02 선언: 소개 문장 + 제1항~제3항 (법·제도·정책 구조 개혁 / 미결 진상조사·기록 / 피해자 회복·연대)
03 걸어온 길: 연표를 장부처럼, 단계 이름은 도장으로
04 후원 약정서: 후원 신청서 양식처럼 구성, 정기 후원(가능)·일시 후원(준비 중)·기부금 영수증(준비 중)·문의를 체크칸으로 표시, 후원금 사용처 4가지, 도장 모양 버튼으로 효성 CMS 연결
05 기록·목소리·모임: 아카이빙(준비 중), 기고글(준비 중), 4/25 파티(지난 일정)
맺음: "끝까지 싸워라, 사랑스럽고 다정하게." + 영상의 물결선을 그려지는 선으로 재현
어르신 가독성용 글자 크기 버튼(A+ A-) 유지

4. 내용상 고친 것 (v9 안에서만)
4/25 파티를 "다가오는 행사"에서 "지난 일정"으로 바꿈 (파티가 실제로 열렸는지는 몰라서 적지 않음)
일시 후원 버튼이 정기후원(효성 CMS)으로 가던 것 제거, "준비 중"으로 정직하게 표시
"후원자 전원 파티 초대" 문구 뺌 (지난 행사라서)
문의처: 사이트 FAQ에 있던 "인스타그램 DM"을 문의 칸에 명시
연표 2024~25의 "이재명 정부" 표현 뺌 (2024년에는 해당 정부가 없었음)

5. SEMI 확인이 필요한 것
발족 연도: 사이트는 2017, Claude 메모리 기록은 2023 발족. 어느 쪽이 맞는지 확인 필요
"9년간 활동 추적", "40건 이상 피해 대응" 숫자는 근거를 몰라 v9에서는 쓰지 않음
4/25 파티 결과(열렸는지, 사진 등)가 있으면 기록으로 넣을 수 있음
survey.html(실행위원 내부 설문)이 공개 주소로 열려 있음, 공개 유지 여부 결정 필요
일시 후원 계좌, 기부금 영수증, 연락 이메일이 정해지면 약정서 칸만 바꾸면 됨
